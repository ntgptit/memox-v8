## Design specificity
The screens are specific to MemoX:
- the defaults apply only to sessions opened afterwards (BR-SETTINGS-004);
- the reset copy rules out "Reset learning progress" (BR-SETTINGS-008);
- a root deck's options cover its sub-decks, and the note names the root;
- "Saved to this device only" matches the local-first voice.

## Priority issues

- **[P1] Screen 26's "Follow the system" line is wrong for a Vietnamese phone.**
  - *Problem:* it reads "Phone is set to Tiếng Việt · falls back to English". With the phone in Vietnamese, `system` resolves to Vietnamese, and the fallback only applies to a language the app lacks (BR-SETTINGS-006).
  - *Fix:* name what `system` resolves to right now. The line reads "Phone is set to {language}" for en/vi, and "{Phone language} isn't available · English" otherwise. The platform locale is read through `PlatformDispatcher`.
  - *Command:* `/impeccable clarify`
- **[P1] Screen 15's footer hides the last note in every state.**
  - *Problem:* "…keeps the options it started with" is cut under the Save bar.
  - *Fix:* the scroll view pads for the footer (`MxAppShell` footer inset), and the note stays reachable at text scale 2.
  - *Command:* `/impeccable adapt`
- **[P2] Screen 25's naming and descriptors.**
  - *Problem:* the page title "Appearance" does not match 23's "Theme" row or the kit's own screen name. The card descriptors "Tokyo Pure" and "Tokyo Nebula" are internal palette names.
  - *Fix:* rule on the title and the descriptors (owner). The recommendation is the title "Theme", with the descriptors "Match phone", "Always light" and "Always dark".
  - *Command:* `/impeccable clarify`
- **[P2] Screen 23 has no read-error state.**
  - *Problem:* the kit has none, but UC-SETTINGS-001 E3 requires one.
  - *Fix:* use `MxErrorState` with the local-first body and Retry, and invent no value. This is recorded as a V8 addition (spec §5.2).
  - *Command:* `/impeccable harden`
- **[P3] Save on 15 is enabled with nothing changed.**
  - *Problem:* the override and defaults frames show an active Save.
  - *Fix:* Save is enabled only when the draft differs from the persisted options and is valid. Otherwise a tap writes a transaction that changes nothing (spec §5.5).
  - *Command:* `/impeccable harden`
- **[P3] Semantics.**
  - Theme cards and language rows are single choices: each is one node, "selected" when chosen.
  - The stepper number is an editable value (spec §5.1).
  - The segmented tray exposes its selected segment.
  - *Command:* `/impeccable audit`

## Minor observations
- **26's sub-lines.** English over "English" is redundant. Each row's sub-line should name the language in the current UI language: "English" · "Tiếng Anh", "Vietnamese" · "Tiếng Việt".
- **The "Saved" toast.** After every settled change on 23 it is frequent, but it is the kit's feedback, and D1 saves per change. Keep it.
- **Disabled values on 15.** With "Use app defaults" on, the disabled 0.38 values are hard to read. The toggle's sub-line repeats them ("Following Settings · 20 cards, created order"), so nothing is lost.
- **The reset dialog.** Cancel is an outline button and "Reset options" is a filled primary one, not destructive. That is right: nothing learnt is lost (BR-SETTINGS-008).
