## Findings

- **The noTarget sheet differs from the kit.** The kit draws a tinted tree glyph and an outline OK; the build shows the neutral folder and a filled OK. The detail file said "As drawn". The cause is the shared `MxDeckPickerSheet` (ruling O11). Fixed in this batch: the difference is now recorded in the detail file 06 (the state row and a deviation row). The code is unchanged, so the move sheets stay consistent.
- **No change: the other kind's rows are not dimmed while selecting.** The kit does not dim them either, so the plan's Expected line was wrong. The rows are untappable, TalkBack marks them disabled, and the note says why.
- **No change: "Delete for good" wraps to two lines at 1x.** The kit wraps it the same way.
- **No change: a deck's meta line ellipsizes at 1x.** The kit ellipsizes it the same way, and the row's TalkBack node carries every fact (D15).
- **No change: the grey fill on the last tapped row.** It is the ink highlight left by the test pointer. The same fill is in `card_selection_*` from before FE-B1, so it is a harness artefact, not a design state.
- **No change: the Trash entry and the empty state reuse `AppIcons.delete`.** The kit uses the same trash glyph in both places.
