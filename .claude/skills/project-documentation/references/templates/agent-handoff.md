# Bounded documentation assignment

MUST fill concrete fields before each investigator or reviewer dispatch:

```text
Role/mode: investigation or independent audit; requested documentation mode
Target: absolute repository root, revision/dirty state, actual loaded skill path
Scope: bounded question and owned source/document areas
Read first: discovered applicable instructions and accepted conventions;
  skill documentation-contract.md and evidence-rules.md
Runtime context: folder/config/stack/domain evidence map and authority states
Sources: raw paths/symbols/decisions/tests; follow relevant references
Criteria: applicable audit-rules.md rows
Output: coverage, including behavior-to-document gaps independently checked
  against raw evidence; claim records; reproducible findings/proposed fixes; actual
  check results; no repository edits
Completion: every assigned item inspected or explicitly unverified with reason
Safety: you are not alone in the worktree. Preserve others' edits. Read-only
  ownership; the coordinator serializes edits and re-reads the latest tree.
```

Follow target model/spend/delegation policy; this skill requires no specific vendor
or model. If compliant delegation is unavailable, disclose sequential self-review.
An auditor gets raw evidence, not a desired verdict. Workers cannot expand edit scope.
