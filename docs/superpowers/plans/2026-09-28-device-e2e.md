# Device scenarios (FE-D3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the eight `DEVICE-E2E` scenarios on an Android device with one command.

**Architecture:**
- `integration_test` phases, one test file per restart, driven by
  `tools/device/run_device_e2e.sh`. The script does what only the OS can: clear
  data, kill, airplane mode, system Back, deep links, installing a release APK.
- Phases talk to the script through `MEMOX-E2E:` output lines, and the script
  passes values back as `--dart-define`.
- Two product changes the scenarios need: a `memox://` deep link and a
  not-found screen for unknown routes.

**Tech Stack:** Flutter 3.47.5, `integration_test` (SDK), go_router, bash + adb.

**Spec:** `docs/superpowers/specs/2026-09-28-device-e2e-design.md`

## Global Constraints

- No third-party package; `integration_test` comes from the Flutter SDK (spec D1).
- Script messages in English; docs under `docs/` in Vietnamese (CLAUDE.md, Language).
- Tests find text through `AppLocalizations` read from the running tree, never a literal (D7).
- Goldens only from `memox-golden:3.47.5`; this plan adds none.
- The Windows gate: `bash .claude/skills/flutter-workflow/scripts/dod_check.sh`.
- Build on this machine with `-Pkotlin.incremental=false` (pub cache and repo on different drives).

## Review Focus

1. **A failed run leaves the device offline.** Airplane mode must be off after any
   exit, including Ctrl-C. Task 3 tests the `trap` by killing a run mid-phase.
2. **A deep link to a route that writes on open.** Every `AppRoutes` path must be
   read-only until the person acts. Task 2 reviews the route table and records the
   result in the spec.
3. **A phase that waits forever.** Every wait has a timeout that names what it
   waited for (`waitFor`, the script's `expect_text`).
4. **Device language not English.** Dart phases read l10n from the tree; the
   script's own `uiautomator` checks set the app locale to `en-US` first.
5. **`install -r` of the next phase keeps the data.** Checked the first time
   IT-PLAT-002 phase b runs. If the data is gone, the design fails; stop and ask.

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';
import 'package:memox/l10n/generated/app_localizations.dart';
import 'package:memox/main.dart' as app;

/// Lines the runner script reads from `flutter test` output (spec D3).
const _prefix = 'MEMOX-E2E:';

void initDeviceBinding() =>
    IntegrationTestWidgetsFlutterBinding.ensureInitialized();

/// The installed app as a person starts it: the real `main()`, database and
/// assets (spec §1).
Future<void> launchApp(WidgetTester tester) async {
  await app.main();
  await waitFor(tester, find.byType(Scaffold));
}

/// Pumps until [finder] finds something; fails naming it after [timeout].
Future<void> waitFor(
  WidgetTester tester,
  Finder finder, {
  Duration timeout = const Duration(seconds: 30),
}) async {
  final end = DateTime.now().add(timeout);
  while (DateTime.now().isBefore(end)) {
    await tester.pump(const Duration(milliseconds: 200));
    if (finder.evaluate().isNotEmpty) return;
  }
  throw TestFailure('Timed out after $timeout waiting for $finder');
}

/// The app's strings in the device's language (spec D7).
AppLocalizations l10nOf(WidgetTester tester) =>
    AppLocalizations.of(tester.element(find.byType(Scaffold).first));

/// Tells the runner script something (spec D3).
void signal(String message) => debugPrint('$_prefix $message');

/// A value an earlier phase signalled, passed on by the script.
String valueOf(String key) => switch (key) {
  'DECK_ID' => const String.fromEnvironment('MEMOX_E2E_DECK_ID'),
  'CHECKPOINT' => const String.fromEnvironment('MEMOX_E2E_CHECKPOINT'),
  _ => throw ArgumentError.value(key, 'key', 'unknown E2E value'),
};

Future<void> tapText(WidgetTester tester, String text) async {
  await waitFor(tester, find.text(text));
  await tester.tap(find.text(text).first);
  await tester.pump(const Duration(milliseconds: 300));
}
```

- [ ] **Step 4:** `tools/device/run_device_e2e.sh`. Its skeleton:
  - `set -uo pipefail`, `PKG=com.memox.memox`.
  - Device selection: `-d`, or the one `adb devices` line.
  - `phase` runs `flutter test "integration_test/$1_test.dart" -d "$DEVICE" --no-uninstall "${DEFINES[@]}"`. It pipes the output through a reader that:
    - echoes each line;
    - on `MEMOX-E2E: back`, runs `adb shell input keyevent KEYCODE_BACK`;
    - on `MEMOX-E2E: value K=V`, writes `$STATE/K`.
    Before each phase, the script adds `--dart-define=MEMOX_E2E_K=V` for every stored value.
  - `reset_app` runs `pm clear` if the app is installed, and clears `$STATE`.
  - `offline_on`/`offline_off` use `cmd connectivity airplane-mode`, and a `trap offline_off EXIT INT TERM`.
  - `expect_text` retries a `uiautomator dump` for up to 40 s.
  - `deeplink` runs `am start -W -a android.intent.action.VIEW -d`.
  - `scenario_IT_PLAT_001` runs `reset_app` then the phase.
  - `scenario_IT_PLAT_006`:
    1. `flutter build apk --release`, then uninstall and install it.
    2. `cmd locale set-app-locales $PKG --locales en-US`, then `logcat -c`.
    3. Launch it, then `expect_text "Start your library"`.
    4. No `FATAL EXCEPTION` or `E/flutter` in `logcat -d`.
    5. Uninstall it.
  - The summary prints PASS/FAIL per ID, and the script exits 1 on any FAIL.
