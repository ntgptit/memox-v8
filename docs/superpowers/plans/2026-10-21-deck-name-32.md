# Deck names at most 32 characters — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every deck name the app writes is at most 32 visible characters (and 128 code points), names already longer are cut by a migration, the server holds the 128 ceiling, and the create and rename dialogs count from the 26th character.

**Architecture:** One rule in `DeckEntity.checkName` serves every write path, as today. A Drift step v17 → v18 cuts long names with raw SQL and logs each cut once the upgrade has committed. A Supabase migration adds a CHECK that `private.push_one` already reports as `VALIDATION_FAILED`. One shared field widget in the deck feature gives both dialogs the counter and the live refusal.

**Tech Stack:** Flutter 3.47.5, Drift (`.drift`, `drift_dev schema` tooling), Riverpod, gen-l10n ARB (en, vi), Supabase Postgres + pgTAP.

**Spec:** `docs/superpowers/specs/2026-10-21-deck-name-32-design.md`

## Global Constraints

- The limit is **32 visible characters** (grapheme clusters, `characters`), counted on the trimmed name, and **128 code points** of the stored form (`storedText`: trimmed, NFC).
- 15–25 characters is a recommendation, never a rule: the counter shows from the **26th** character, as "{length} / {max}".
- Typing is never blocked and a paste is never cut (no `maxLength`).
- Names longer than the rule are **cut by the v17 → v18 migration** (owner N3); there is no grandfather path anywhere.
- The server checks `char_length(name) <= 128` only; it never counts graphemes.
- No colour, type-scale, layout or other business-rule change; no `fontWeight` outside `lib/core/theme/`; features use `Mx*` widgets only.
- No `else`; files at most 400 logical lines; search with `rg` only.
- Copy: `deckRejectionNameTooLong` "Keep the name to 32 characters." / "Tên dài tối đa 32 ký tự."; `importRowDeckNameTooLong` "Deck name over 32 characters" / "Tên deck dài quá 32 ký tự"; `deckNameLength` "{length} / {max}" in both.
- ARB metadata order: `placeholders` first, then `description` (guard `memox.i18n.arb_entry_needs_description`).
- A released migration never changes; `schemaVersion` goes up by one.
- Gates: `dod_check.sh`, `run_goldens.sh`, `npx supabase db start` + `npx supabase test db`, and `bash tools/supabase/run_auth_it.sh` (the PR changes `supabase/migrations/`).

## Plan rulings (made while writing this plan, against the spec)

- **P1, server check.** `private.push_one` maps `check_violation` to `VALIDATION_FAILED` (`20260928000000_deck_sync.sql`, its later `create or replace` copies keep the handler). So the CHECK alone gives the spec's rejection, and covers every insert path (`deck_upsert`, the account merge). `deck_upsert` is not rewritten. Spec §6 is corrected in Task 5. Cost if wrong: one more function body in the migration.
- **P2, counter tone.** `MxTextField.counter` is a plain line with no error tone. Giving it one is a shared-widget change for a cosmetic gain, so the counter keeps the field's style and the error message carries the state. Spec §7 is corrected in Task 5. Cost if wrong: a later `MxTextField` change.
- **P3, spoken counter.** `MxTextField.counter` has no semantics label. TalkBack reads "26 / 32", as it does in the tag rename dialog today. Spec §7 is corrected in Task 5. Cost if wrong: same shared change as P2.
- **P4, long-name tests.** A name longer than 32 can still arrive from a server written by an older build (pull never refuses). The four UI tests that need a name of three lines or more write it raw, through a new fixture `setDeckNameRaw`, so they keep their purpose. Cost if wrong: none for the app.

## Review Focus

1. **A name of exactly 32 characters made of combining marks or a ZWJ emoji** (e.g. 32 × "👨‍👩‍👧", 160 code points). Expect it refused by the app (over 128) and cut by the migration to the longest run of whole characters within 128 code points — never a broken emoji. Pinned in Task 1 (rule table) and Task 2 (migration table).
2. **A trashed deck with a long name, then restored.** Expect the migration to cut it too, so the restore brings back a valid name. Pinned in Task 2.
3. **Rename opened on a 40-character name (left from before the migration on another device, pulled later).** Expect the field to show "40 / 32", the error, Save locked, and the text whole. Pinned in Task 4.
4. **A name whose cut leaves a trailing space** ("…32nd character is a space…"). Expect the stored name trimmed at its end, never blank. Pinned in Task 2.
5. **Rename of a short name while the stream re-emits.** Expect no counter until the 26th character and no error flicker. Pinned in Task 4 (the "short" row).

```dart
  /// BR-DECK-020, in characters as a person sees them (grapheme clusters).
  static const maxNameLength = 32;

  /// BR-DECK-020: the recommended length; the name dialogs count from the
  /// next character on (owner 2026-10-21).
  static const recommendedNameLength = 25;

  /// BR-DECK-020: the server's ceiling, in code points of the stored form,
  /// which Postgres can count where it cannot count characters (owner
  /// 2026-10-21).
  static const maxNameCodePoints = 128;

  /// The characters of [name] as BR-DECK-020 counts them.
  static int nameLength(String name) => name.trim().characters.length;

  /// BR-DECK-020: not blank after trim, at most [maxNameLength] characters
  /// and [maxNameCodePoints] code points once stored.
  static Outcome<void, DeckRejection> checkName(String name) {
    final trimmed = name.trim();
    if (trimmed.isEmpty) return const Rejected(DeckRejection.blankName);
    if (trimmed.characters.length > maxNameLength) {
      return const Rejected(DeckRejection.nameTooLong);
    }
    if (storedText(name).runes.length > maxNameCodePoints) {
      return const Rejected(DeckRejection.nameTooLong);
    }
    return const Ok(null);
  }
```

- [ ] **Step 3: Write the step**

Create `lib/core/database/migrations/deck_name_length_migration.dart`:

```dart
import 'package:characters/characters.dart';
import 'package:drift/drift.dart';

// Migration v17 → v18 (deck name 32 spec 2026-10-21 §5). Released once,
// then never changed. Raw SQL only: a step never calls application
// queries (.claude/skills/flutter-drift/references/migrations.md).

/// BR-DECK-020's bounds as v18 ships them, copied so this step never moves
/// when the rule does.
const _maxCharacters = 32;
const _maxCodePoints = 128;

/// A deck name the step shortened.
typedef DeckNameCut = ({String id, String from, String to});

/// Cuts every deck name over BR-DECK-020's bounds (Trash included) to its
/// longest start of whole characters within both, trimmed at its end, and
/// stamps `updated_at` with [now]; the capture trigger queues each for sync.
/// A stored name starts with a non-space, so a cut is never blank.
///
/// Decks are read [pageSize] rows at a time, by `id`, so a large library
/// upgrades in bounded memory.
Future<List<DeckNameCut>> shortenDeckNames(
  DatabaseConnectionUser db, {
  required DateTime now,
  int pageSize = 1000,
}) async {
  final cuts = <DeckNameCut>[];
  var after = '';
  while (true) {
    final page = await db
        .customSelect(
          'SELECT id, name FROM deck WHERE id > ? ORDER BY id LIMIT ?',
          variables: [Variable<String>(after), Variable<int>(pageSize)],
        )
        .get();
    for (final row in page) {
      final name = row.read<String>('name');
      final cut = _cut(name);
      if (cut == name) continue;
      final id = row.read<String>('id');
      await db.customUpdate(
        'UPDATE deck SET name = ?, updated_at = ? WHERE id = ?',
        variables: [
          Variable<String>(cut),
          Variable<DateTime>(now),
          Variable<String>(id),
        ],
      );
      cuts.add((id: id, from: name, to: cut));
    }
    if (page.length < pageSize) return cuts;
    after = page.last.read<String>('id');
  }
}

/// The longest start of whole characters of [name] within both bounds.
String _cut(String name) {
  final kept = StringBuffer();
  var count = 0;
  var codePoints = 0;
  for (final character in name.characters) {
    final size = character.runes.length;
    if (count == _maxCharacters || codePoints + size > _maxCodePoints) break;
    kept.write(character);
    count++;
    codePoints += size;
  }
  return kept.toString().trimRight();
}
```

/// The deck-name field of the create and rename dialogs (BR-DECK-020;
/// owner 2026-10-21): the count from the 26th character, and a name over
/// the limit said as it is typed, so the confirm can lock before a tap.
/// [submitted] is the reason the last write returned (a blank name is said
/// only then). Nothing is cut: a paste stays whole.
class DeckNameFieldWidget extends StatelessWidget {
  const DeckNameFieldWidget({
    super.key,
    required this.controller,
    required this.submitted,
    required this.onChanged,
    required this.onSubmitted,
  });

  final TextEditingController controller;
  final DeckRejection? submitted;
  final ValueChanged<String> onChanged;
  final ValueChanged<String>? onSubmitted;

  /// Whether [name], as typed, breaks the length rule of BR-DECK-020.
  static bool isTooLong(String name) => switch (DeckEntity.checkName(name)) {
    Rejected(reason: DeckRejection.nameTooLong) => true,
    _ => false,
  };

  @override
  Widget build(BuildContext context) {
    final l10n = context.l10n;
    final name = controller.text;
    final length = DeckEntity.nameLength(name);
    var reason = submitted;
    if (isTooLong(name)) reason = DeckRejection.nameTooLong;
    return MxTextField(
      controller: controller,
      label: l10n.deckNameHint,
      counter: length > DeckEntity.recommendedNameLength
          ? l10n.deckNameLength(length, DeckEntity.maxNameLength)
          : null,
      errorText: switch (reason) {
        null => null,
        final reason => l10n.deckRejection(reason),
      },
      textInputAction: TextInputAction.done,
      onChanged: onChanged,
      onSubmitted: onSubmitted,
    );
  }
}
