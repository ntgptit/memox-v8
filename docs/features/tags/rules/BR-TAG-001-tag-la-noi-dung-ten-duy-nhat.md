## Rule

Tag MUST là nội dung, quan hệ nhiều-nhiều với thẻ. Tên tag MUST không rỗng sau trim, MUST tối đa 50 ký tự, và MUST là duy nhất không phân biệt hoa thường.

**Enforced by:** rule + db
**Liên quan:** BR-SRS-021

## Lý do

Các rule dưới đây là mô hình dữ liệu cốt lõi của tag; mục "Quản lý tag" bên dưới **không** phát biểu lại chúng.
