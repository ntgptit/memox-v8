# Regression findings

These are the defects and gaps found in the closing acceptance of the ForUI
migration, 2026-10-18, fixed or open, with their evidence. The branch is
`claude/ecstatic-lovelace-s80gci`, from master `aa4d943a`. The whole-app
Impeccable finding ledger (113 findings from 2026-10-17) is in
[POST_MIGRATION_ACCEPTANCE.md](POST_MIGRATION_ACCEPTANCE.md) §4. This file
holds what this cycle found or decided.

Each finding has an **origin**:

- **Pre-existing**: the defect was in the app before the migration, or its
  mechanism does not depend on the component library.
- **Migration**: the migration introduced it or left it behind.
- **Docs**: the documentation disagreed with the code.
- **Environment**: the cloud container could not run something.
- **Product scope**: outside the product's committed targets.

No finding is a **critical** functional regression. Linear could not take new issues (the workspace is at its plan's limit), so the follow-ups that CLAUDE.md would make sub-issues are recorded here. None breaks a primary
journey at the default text scale on the three verified phone sizes.
